# Khavaran Desk

Custom RustDesk client with an independent configuration namespace and automatic ID range. Windows build runs on pushes to main.

Upstream source is pinned to a7f2260203befb7e9c70b585219f0f0b5ca57703. The workflow retrieves the source and applies the included patches.

License: AGPL-3.0; upstream copyright notices remain intact. Windows installers are unsigned. No server address, password or private key is embedded. Configure your own ID server, relay and public key in Settings → Network.

This repository contains a build pipeline; successful compilation and device testing are required before treating the client as production ready.
